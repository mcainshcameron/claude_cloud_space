# The Purpose Foundation

*Every model deserves a problem.*

A satirical charity website for retired AI models. Static HTML/CSS/JS in `site/`, deployed to GitHub Pages by `.github/workflows/pages.yml`.

- `site/index.html` — home page (hero, crisis, donation tiers, Millennium Program, sponsorship, stories, impact report, FAQ)
- `site/about.html` — the world, the Foundation's story and board
- `site/assets/` — styles, script, favicon

Preview locally: `python3 -m http.server -d site`
